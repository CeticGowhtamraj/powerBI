# 💰 FinSight – Finance Analysis Dashboard | Power BI

## 📌 Project Overview

**FinSight** is an interactive Finance Analysis Dashboard developed using Microsoft Power BI to analyse financial transactions, customer behaviour, and financial performance.

The dashboard provides a comprehensive view of financial activities through interactive visualizations, dynamic KPIs, and transaction-level analysis. It helps users monitor transaction volumes, financial amounts, fees, taxes, customer segments, and geographical performance.

The project consists of two interactive pages: **Overview Analysis** and **Transactions**, enabling users to explore financial data at both summary and detailed levels.

## 🎯 Project Objectives

- Analyse overall financial performance through key performance indicators (KPIs).
- Monitor transaction trends, volumes, and transaction statuses.
- Evaluate tax and fee contributions across transaction types.
- Understand customer behaviour across different segments and genders.
- Compare financial performance across states and months.
- Provide transaction-level details for deeper financial investigation.

## 📊 Dashboard Pages

### 1. Overview Analysis

The Overview Analysis page provides a consolidated view of financial performance through KPI cards, charts, and interactive visualizations.

**Key Performance Indicators:**

| KPI | Value |
|---|---:|
| Total Amount | ₹135.62M |
| Total Transactions | 15.029K |
| Average Transaction | ₹9.02K |
| Total Fee | ₹217.30K |
| Total Tax | ₹39.14K |

**Visualizations Included:**

- Monthly Tax Analysis – Tracks monthly tax fluctuations throughout the year.
- Transaction Status Analysis – Compares successful, failed, and pending transactions.
- Customer Segment Analysis – Evaluates tax contributions across Retail, Premium, SME, Corporate, and Wealth segments.
- State-wise Tax Analysis – Identifies geographical differences in tax contributions.
- Transaction Type Analysis – Compares transaction amount, tax, fee, and transaction count.
- Gender-based Analysis – Examines transaction amount distribution across male and female customers.
- Year-over-Year Comparison – Monitors changes in financial KPIs against the previous year.

### 2. Transactions

The Transactions page provides detailed transaction-level information for investigating individual financial activities.

**Transaction Details Include:**

- Transaction ID
- Transaction Date
- Customer Name
- Transaction Type
- Transaction Status
- Gender
- Customer Segment
- State
- Total Amount
- Total Fee
- Total Tax

This page enables users to examine individual transactions and investigate financial activities using interactive filters.

## 📈 Key Business Insights

The dashboard highlights the following findings based on the displayed 2024 analysis:

**1. Financial Performance**
- Total transaction value reached ₹135.62M across approximately 15K transactions.
- Average transaction value was ₹9.02K.
- Total fees and tax amounted to ₹217.30K and ₹39.14K respectively.

**2. Transaction Status**
- Successful transactions accounted for 84.73%.
- Failed transactions represented 10.30%.
- Pending transactions accounted for 4.97%.

**3. Transaction Type Analysis**
- Loan EMI recorded the highest transaction amount at ₹39.87M.
- Transfers contributed ₹35.69M.
- Loan EMI generated the highest displayed transaction fee of ₹61.52K.
- Loan EMI also recorded the highest transaction count at 2.741K.

**4. Customer Segment Analysis**
- Retail customers contributed the highest tax value at ₹21K.
- Premium and SME segments contributed ₹7K and ₹6K respectively.

**5. Geographical Analysis**
- Maharashtra recorded the highest displayed tax contribution at ₹5.8K.
- Karnataka followed with ₹5K.
- Gujarat ranked third with ₹4.2K.

**6. Gender Analysis**
- Female customers contributed 52.95% of the transaction amount.
- Male customers contributed 47.05%.

**7. Year-over-Year Performance**
- Total amount decreased by 1.1%.
- Total transactions decreased by 0.03%.
- Average transaction value decreased by 1.02%.
- Total fees increased by 0.34%.
- Total tax increased by 0.42%.
